# Streamlab

Static migration of the published Streamlabplatform Wix website.

- Source: https://www.streamlabplatform.com/
- Static entry point: `index.html`
- Wix media mirror: `static.wixstatic.com/`
- Additional Wix Media Manager archive: `migration-assets/wix-media-manager.zip`
- Migration notes: `migration-assets/WIX-MIGRATION-NOTES.md`

This repository contains the public/static mirror. Wix Studio editor data, hosted Velo runtime, Wix app internals, CMS/database services, form submissions, and other server-side Wix functionality are not portable as ordinary static GitHub files.
